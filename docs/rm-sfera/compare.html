ООО «Сфера»

+7 (8342) 25-34-42

Сфера. газовые баллоны

Кого спросить. коммерческий директор Тарасова А.Е.

Пометка. Звонить последней: прайс-лист говорит «отгрузка только по ранее заключённым договорам»

Три проверенные проблемы текущего сайта

  1. Кнопка «Скачать Прайс-лист» открывает файл informaciya.docx. В файле одна фраза: «В настоящий момент отгрузка баллонов осуществляется в рамках заключенных раннее действующих договоров». Цен и моделей в файле нет. В слове «раннее» ошибка.
  2. На страницах моделей разные данные. На странице БГ-170 написано «Объем: 100 л». На странице БГ-65 написано «Объем: 50 л». Название и размеры обеих моделей говорят о другом объёме.
  3. На главной странице нет каталога. Главная называется «О компании» и состоит из текста. На телефоне первый экран занимает один логотип. Чтобы увидеть баллоны, нужно открыть меню и выбрать «Продукция». Там список из 20 названий без таблицы.

Первая фраза оператора

«Добрый день. Меня зовут [имя]. Мы сделали для завода «Сфера» демо нового сайта. Можно показать его за две минуты?»
