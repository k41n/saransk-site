# Шаблон демо-сайта для холодного звонка
## Структура папки
- docs/<имя>/index.html — одна страница, без сборки.
- docs/<имя>/img/ — реальные фото, до 2 МБ в сумме, относительные пути.
- docs/<имя>/call.md — сценарий звонка.
- docs/<имя>/_preview_desktop.png и _preview_mobile.png — снимки.

## Обязательный head
- lang="ru", charset, viewport.
- meta robots noindex,nofollow.
- title и description с реальным названием компании.
- favicon из img/logo.svg.
- Google Fonts с кириллицей (Unbounded для заголовков, Onest для текста). Для другого клиента выберите другую пару.
- Подвал: «Демо-версия. Материалы принадлежат <компания>».

## Порядок работы
1. Скачайте главную, каталог, контакты, прайс. Извлеките текст.
2. Возьмите цвета из логотипа и CSS клиента. Запишите токены в :root.
3. Соберите 8-15 фото. Сожмите: magick -resize, качество 76.
4. Верстайте блоки: первый экран, продукция, марки, о заводе, опт, контакты.
5. Снимите экраны 1280 и 390. Нарежьте magick -crop и просмотрите.
6. Проверьте scrollWidth равен clientWidth.
7. Напишите call.md. Каждый пункт проверьте на живом сайте.

## Что сработало
- Прозрачные PNG упаковок (magick floodfill с углов) для первого экрана.
- Фото с белым фоном: mix-blend-mode:multiply на цветной карточке.
- Сетка 12 колонок, разные spans, оттенки фирменного цвета для карточек.
- Волна из логотипа как SVG под первым экраном.
- Таблица из прайс-листа вместо выдуманных цифр.
- Архивные фото с подписями со снимков.

## Ошибки, которые исправили
- Playwright блокирует file://. Запустите python3 -m http.server в docs.
- Снимки пишите только в каталог проекта, не в /tmp.
- loading="lazy" ломает fullPage-снимок. Уберите.
- Multiply на наложенных упаковках просвечивает. Используйте прозрачные PNG.
- Слишком тяжёлые заголовки Unbounded: вес 400-500, размер меньше.
- Колонка «срок» переносилась на телефоне. Задайте nowrap.
- Не выдумывайте год основания, цифры, награды, отзывы. Нет данных значит нет блока.
