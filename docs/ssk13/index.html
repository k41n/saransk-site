Как делаем отводы

Делаем отводы из бесшовной трубы. Размеры проверяем у всех готовых деталей.

  1. Труба

    Берём сортовую бесшовную горячедеформированную трубу по ГОСТ 8732-78. Марка стали отводов: сталь 20.

  2. Горячая протяжка

    Протягиваем разогретую заготовку по рогообразному сердечнику. Так получается крутоизогнутый отвод.

  3. Проверка

    Проверяем размерные характеристики у 100% готовой продукции.

  4. Паллеты

    Укладываем отводы на деревянные паллеты 1 × 1,2 м. Затем отгружаем.
