## Три проверенные проблемы текущего сайта
1. На телефоне текст обрезается. Страница имеет фиксированную ширину 770 пикселей. Справа абзацы уходят за край экрана.
2. Страница «Новости» пустая. На ней нет ни одной новости, только часы посетителя. Страница «Магазин» тоже пустая: ссылки «Прайс лист» никуда не ведут.
3. Телефоны на странице «Контакты» это обычный текст. С телефона их нельзя набрать нажатием. Кроме того, адрес с https не открывается, сайт работает только по http.

Проверьте каждый пункт на сайте перед звонком. Не называйте другие проблемы.

- Первый экран: что принимают, телефон, кнопка «Позвонить».
- Список из 16 видов лома, сгруппированный по металлам. Все виды взяты со страницы «Покупка».
- Условия покупки: габарит и негабарит, предоплата постоянным клиентам.
- Марки алюминиевых сплавов по ГОСТ 1583-93: АК5М2, АК9М2, АК9, АК12М2, АК8М, АВ87.
- Три реальные фото с сайта: чушки, плавка, печь.
- Контакты: телефоны открываются нажатием. Схема проезда из Ульяновска есть.
