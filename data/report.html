Правила для оператора

  • Отправляйте клиенту только ссылку на демо. Список и страницы сравнения внутренние.
  • Говорите только о трёх проверенных проблемах со страницы сравнения.
  • Не говорите «у вас плохой сайт» и «у вас нет сайта».
  • Не называйте цену.
  • Не называйте значки в демо ssk13, nano4 и «Мордовских узоров» логотипом компании: их нарисовали мы.

Как продолжить работу с Claude Code без автора

  1. Склонируйте репозиторий целиком. Папка data лежит в репозитории рядом с папкой docs. Она содержит рейтинг, списки и генератор страниц.
  2. Дайте доступ на запись в k41n/saransk-site. Либо сделайте fork и включите GitHub Pages в новом аккаунте. Тогда адреса демо изменятся.
  3. Держите правила в файле CLAUDE.md. Файл уже лежит в репозитории. Claude Code читает его сам в начале каждой сессии. Память прежней подписки в новую подписку не переходит.
  4. Начинайте каждую сессию со стартового промпта ниже. Одна задача — одна сессия. Для новой задачи выполните /clear.
  5. Механику отдавайте субагентам на Sonnet. Вёрстка одного демо стоит около 130–150 тысяч токенов субагента и занимает 15–20 минут.
  6. Проверяйте результат по снимкам. Отчёт субагента не заменяет просмотр снимков _preview_desktop.png и _preview_mobile.png.
  7. Публикацию выполняйте в ручном режиме разрешений. Автоматический режим блокирует отправку страниц с телефонами и фамилиями в публичный репозиторий.

Стартовый промпт для новой сессии

Ты продолжаешь проект «Холодные звонки по Саранску». Мы продаём компаниям новый сайт за 2–3 дня и 25 раундов правок.

Что уже есть:
- Репозиторий k41n/saransk-site. Папка docs опубликована на GitHub Pages: https://k41n.github.io/saransk-site/
- docs/<slug>/index.html — демо нового сайта клиента. docs/<slug>/call.md — сценарий звонка. docs/<slug>/compare.html — страница «Было / Стало». docs/index.html — список для операторов.
- docs/_BRIEF.md — правила вёрстки демо. docs/_PATTERN.md — приёмы и ошибки. Прочитай оба файла перед работой.
- Папка data: companies.csv — рейтинг 51 компании, improvable_with_phone.csv — 23 компании для звонка, call_list_top10.csv — первая десятка, build_sales_site.py — генератор страниц сравнения и списков.

Жёсткие правила:
1. Демо делай только в корпоративных цветах клиента. Цвета проверяй по CSS и логотипу.
2. Ничего не выдумывай: никаких цифр, наград, отзывов, цен и фото, которых нет на сайте клиента.
3. «Сайт не найден» не значит «сайта нет». Оператор не говорит клиенту «у вас нет сайта».
4. Поиск, оценку, вёрстку и снимки отдавай субагентам на Sonnet. Главная модель планирует и проверяет результат по снимкам.
5. Каждая страница имеет meta robots noindex,nofollow. Вёрстка статическая, пути относительные.
6. Клиенту уходит только ссылка на демо. Список, compare.html и call.md внутренние.
7. Перед публикацией спроси разрешение. Публикация: git add docs, git commit, git push.

Технические заметки:
- Снимки на ширине 390 делай через npx playwright screenshot --channel chrome --viewport-size=390,900 --full-page. Headless Chrome не снимает окно уже 500 px.
- Страницу выше 16384 px снимай частями и склеивай через magick.
- После правки call.md запусти python3 data/build_sales_site.py. Миниатюры docs/_assets/thumbs/<slug>.jpg генератор не обновляет: обрежь верх _preview_desktop.png до 1280x800 и уменьши до 640x400.
- Новую компанию добавь в список компаний внутри data/build_sales_site.py.
